# 知识库示例（Knowledge Base Demo）

> 本文件是"用户自备知识库"的**示例**：复制本文件（或自己编写 txt / md / pdf）到
> `data/knowledge/` 目录后，运行 `cugeopractor index` 重建索引，即可让 LLM 在对话中检索到这些内容。
> 示例内容仅供演示，请替换为实际需要检索的资料。

## 什么是知识库

知识库是项目内置的**本地检索增强（RAG）**数据源：

- 文档存放目录：`data/knowledge/`（由 `CUGEOPRACTOR_KNOWLEDGE_DIR` 配置）
- 支持的格式：`.txt`、`.md`、`.pdf`
- 索引方式：文档按固定窗口切块 → 向量化 → 写入本地向量库（`data/vectorstore/`）
- 检索方式：对话时 LLM 通过 `knowledge_search` 工具按相似度检索相关段落，并附来源引用

## 何时使用知识库

适合把**长期稳定的资料**放入知识库，例如：

- 校历、作息时间表
- 校园服务办事指南（一卡通、宿舍、图书馆等）
- 专业培养方案、选课规则
- 常用表单与联系方式

不适合放入的内容：

- 时效性强的公告（应使用实时查询，如 `/live_news`）
- 需要登录态的个人数据（课表、成绩等，走连接器实时获取）

## 写入后如何生效

```bash
# 1. 把文档放入 data/knowledge/
# 2. 重建索引（新增/修改/删除文档后都需要）
cugeopractor index

# 3. 对话时自动生效
cugeopractor chat
# 例：问「校历第一周是什么时候」→ LLM 检索知识库并回答
```

## 索引状态查看

```bash
cugeopractor status
# 输出：知识库 : N 块（目录 data/knowledge）
```

- `N` 为知识库中的文本块总数（文档被切分成 800 字符的块，相邻块重叠 100 字符）
- 索引为 0 说明目录为空或未执行过 `cugeopractor index`
