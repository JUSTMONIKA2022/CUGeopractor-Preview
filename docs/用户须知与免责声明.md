## 一、项目性质

本软件是一个开源的个人本地部署工具：由使用者自行配置 LLM API，通过 Agent 工具调用方式，
访问与整理使用者指定的信息渠道（官网、知乎、B站、贴吧、小红书、教务系统等）中的公开或
使用者本人有权访问的数据。

本软件**不内置任何凭据**（密钥、账号、Cookie 均由使用者自行配置并保管），**不托管任何数据**，
数据只存在于使用者本机。

## 二、使用者责任

1. **行为自担**：本软件的所有数据获取行为均由使用者自行配置、自行发起。使用者应对
   使用本软件过程中的一切行为及其后果**承担全部责任**，包括但不限于：
   - 访问、抓取、整理各平台数据的行为是否违反被访问平台的服务条款；
   - 是否超出本人权限访问数据；
   - 抓取数据的频率与规模是否对被访问平台造成影响；
   - 对抓取所得数据的使用方式。
2. **凭据自持**：使用者配置的账号、Cookie、会话等凭据仅用于本机运行，应由使用者妥善保管；
   因凭据泄露、被盗用、被平台封禁等产生的一切后果由使用者自行承担。
3. **遵守条款**：使用者应自行阅读并遵守所访问平台（含各高校系统）的服务条款与使用规范。
4. **被访问平台的处置**：被访问平台对访问/抓取行为的任何限制（含风控、封禁、账号限制），
   均属平台与使用者之间的事宜，项目方不介入、不担保结果。

## 三、软件能力边界

1. 本软件**不内置、也不承诺绕过**任何平台的登录验证、安全验证、验证码机制；
   当目标平台实施安全验证/风控时，软件如实返回状态提示，由使用者自行决定后续操作。
2. 本软件不保证任何数据源的可用性、完整性、时效性；接口/页面结构变化可能导致部分
   功能失效，项目方不承担由此产生的损失。
3. 本软件按"原样"提供（AS-IS），不附带任何明示或默示的担保。
