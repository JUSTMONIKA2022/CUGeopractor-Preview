# 《用户协议》模板

> 状态：**草稿，待执业律师复核**。以下为要点式模板，正式发布前须由律师完善为可签署文本。

## 1. 协议双方
- 甲方：项目作者 / 开源维护者（"本项目方"）
- 乙方：使用者（部署与使用本项目软件的个人或组织）

## 2. 授权范围
- 本项目依据 Apache-2.0 许可证授权乙方使用、修改与再分发；
- 乙方可在个人设备或自有服务器上部署本项目，用于个人或所在机构内部用途。

## 3. 乙方义务
1. 遵守国家法律法规与本项目"红线"（见 README 第 5 节）：不得将本项目用于越权访问、绕过认证、批量抓取他人信息、发布虚假信息等；
2. 自行妥善保管所配置的 API 密钥与校园系统账号，因密钥泄露产生的后果由乙方承担；
3. 不得以任何高校名义（含校名、校徽、标志性建筑图）发布信息或开展活动；
4. 若乙方将服务对外开放，应自行办理适用的备案、标识与安全评估义务。

## 4. 本项目方义务与免责
- 本项目方按"现状"提供软件，不承诺特定功能或安全保证；
- 本项目方不对乙方使用软件产生的任何直接或间接损失承担责任；
- 本项目方不代收、不存储乙方密钥、账号与数据。

## 5. 争议解决
- 本协议适用中华人民共和国法律；因本协议产生的争议，双方应友好协商，协商不成的，提交本项目方所在地有管辖权的人民法院诉讼解决。

## 6. 其他
- 本项目方保留更新本协议的权利，更新后于仓库公告生效。
